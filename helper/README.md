# Flick for Windows

One app: the Flick window (send, receive, pair) plus the built-in remote your phone uses
(battery, screenshot, media, slides, open apps, trackpad, keyboard, lock, sleep, restart, shut down).

## Install
1. Download **Flick-Setup.exe** from Releases → *Flick for Windows*.
2. Open it. (SmartScreen: **More info → Run anyway**.) Flick installs and opens.
3. Allow it if Windows Firewall asks.

Flick appears in the Start menu and on the desktop. Closing the window keeps it near the clock so your
phone can still reach the laptop. Right-click that icon → **Quit Flick** to stop it.

## Pair your phone
Phone: Flick → **Devices** → tap your laptop → click **Yes** on the laptop if the codes match.

## Security
- Only phones you approve on the laptop can control it.
- Each phone gets its own key; every command is encrypted, signed, time-stamped and can't be replayed.
- A phone can only press Flick's buttons — it can't run programs or read files.
- Windows shows a notification when a phone takes a screenshot, locks, restarts or shuts down the laptop.

## Uninstall
Settings → Apps → Flick → Uninstall.
