# Flick

AirDrop-style sharing between iPhone, Android and Windows — and a remote for your laptop.

- **Flick to send** photos, videos, files, scans and links. Preview before you accept.
- **Remote:** battery, screenshot, media, slides, open apps, trackpad, keyboard, lock, sleep, restart, shut down.
- **Private:** pair once with a code you confirm on both devices. Files go device-to-device; remote commands are encrypted per device.

## Use it
- **Phone:** open the Flick site in Safari/Chrome → Share → **Add to Home Screen**.
- **Laptop:** open the site in Chrome/Edge → **Install**. For the remote, get **Flick.exe** from Releases → *Flick for Windows* (see `helper/README.md`).
