# Flick

AirDrop-style sharing between iPhone and Windows. Flick to send, mirror your screen, control your laptop.

- **Web app** (this folder): deployed on Netlify. Add to Home Screen on iPhone (Safari), Install in Chrome/Edge on Windows.
- **helper/**: Flick Helper for Windows — iPhone screen mirroring (via UxPlay) and phone-to-laptop shortcuts. See `helper/README.md`.
